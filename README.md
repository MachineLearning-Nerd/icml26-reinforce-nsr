## What the paper studies

The paper analyzes the noise-to-signal ratio (NSR) of a REINFORCE policy-gradient
estimator:

```text
NSR = estimator variance / squared norm of the true policy gradient.
```

It derives closed-form one-step linear-quadratic-Gaussian moments, an exact
finite-horizon Gaussian moment-evaluation procedure, an exact polynomial-system
extension, and a general nonlinear-policy variance upper bound. The central
mechanism is that NSR is non-uniform and can grow sharply as policy covariance
shrinks, making stochastic optimization less reliable near an optimum.

## Reproduce

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r repro/requirements.txt
.venv/bin/python repro/src/publication_gate.py
```

The gate regenerates the independent verification, checks the pinned source
anchors, runs the focused tests, validates the cumulative claim gate, rebuilds
the hash-bound evidence bundle, and writes both canonical gate copies. To run
the producer and checks separately:

```bash
.venv/bin/python repro/src/verify_reinforce_nsr.py
.venv/bin/python repro/src/cumulative_science_gate.py
.venv/bin/python repro/src/build_evidence_bundle.py
.venv/bin/python -m pytest -q repro/tests
```

The verifier uses deterministic CPU calculations: degree-8 Gauss-Hermite
quadrature for the exact moment comparisons, covariance recursion and finite
differences for finite horizons, a 61×61 NSR landscape, an 80-point
small-policy-noise blow-up sweep, and 48 nonlinear bound cells.
